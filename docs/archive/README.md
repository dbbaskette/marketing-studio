# Archive

Nothing in this folder describes current behaviour. It keeps Marketing Studio's
completed plans, design specs, dated audits, measurements and verification records as
they were written, so the reasons behind the code can still be read. For how things
work now, start from the [README](../../README.md), [the architecture](../architecture.md),
[testing](../testing.md) and [the release notes](../release-notes.md).

| Here | What it is |
| --- | --- |
| [`superpowers/plans/`](superpowers/plans/) and [`superpowers/specs/`](superpowers/specs/) | Implementation plans and design specs, each dated in its name |
| [`design/`](design/) | The November 6, 2026 UI audits (Golden Gate 2.1 and visibility), with their screenshots |
| [Marketing Studio spec and plan](marketing-studio-spec-and-plan.md), [research component spec](research-component-spec.md) | The first proposals for the suite and its shared research component |
| [Infographic Studio spec](infographic-studio-spec.md), [implementation plan](infographic-studio-implementation-plan.md) | Infographic Studio's first specification and build plan |
| [Verification](verification.md), [4.0.0 verification](verification-v4.0.0.md), [refinement review](refinement-review.md) | Verification and review records of early releases |
| [Responsiveness contracts](research-responsiveness-contracts.md), [early evidence](early-evidence-measurement.md), [incremental polling](incremental-polling-measurement.md), [render performance](render-performance-measurement.md), [provisional preview spike](provisional-preview-spike.md) | Baselines and measurements from the November 2026 audit roadmap |

Each studio keeps its own history in its `docs/archive/` folder, so it still ships with
the studio: [Blog Studio](../../studios/blog/docs/archive/README.md),
[Presentation Studio](../../studios/presentation/docs/archive/README.md) and
[Training Studio](../../studios/training/docs/archive/README.md).

Point-in-time records that every package ships stay where they are, with a note at
their top: [the repository consolidation](../migration-plan.md) and
[the audit integration evidence](../audit-integration-evidence.md).

Links inside these pages are kept working where their target only moved. Paths written
as plain text (in backticks) are left as they were written.

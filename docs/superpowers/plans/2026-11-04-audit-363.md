# Issue 363 — provisional preview feasibility

## Specification

Measure first visible useful pixels, not just first file appearance, using the
existing pinned Harness Slides 0.17.0 local renderer and an isolated read-only
viewer. Compare cold, unchanged and one-slide edit cases at 6, 30 and 100 slides.
A candidate preview must carry attempt/source identity, a hash and decoded image;
never expose final approval. Observe cancellation/supersession and corrupt/missing
outputs, and preserve the existing verified bundle boundary and cache.

## Plan

1. Build a disposable experiment that projects the first finished raster into an
   attempt-bound viewer. Record browser decode/two-frame acknowledgement separately
   from raster availability and sealed-bundle completion.
2. Run representative synthetic decks without providers, Google, user state or a
   second renderer. Test the provisional guard and existing helper cache failure
   cases. Record gaps between the prototype and the full dependency contract.
3. Adopt only if the measured benefit and binding are sufficient; otherwise record
   a bounded decision to retain the current production boundary. Publish the
   experiment/report in one PR, then merge it before the final documentation PR.

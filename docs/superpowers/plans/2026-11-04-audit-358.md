# Infographic Studio preview state — #358

## Spec and plan

Home, the editing desk, save confirmation and recovery controls must agree about
whether a preview exists for the current content. A saved scene alone is not a
rendered preview. An older failed attempt remains history after an edit and must
not offer retry instructions for the wrong revision.

1. Share bounded validated delivery-manifest reads between the desk and Home;
   classify never rendered, current preview and earlier preview without reading
   generated image bytes or source content for Home.
2. Match save confirmations to Create preview versus Update preview.
3. Label superseded failures explicitly and remove misleading composition/artwork
   retry language. Preserve current local-only retry and exact revision guards.
4. Verify failure → edit → create → edit → update with synthetic renderers and one
   native browser journey; run complete affected recovery/workbench/delivery modules.

No automatic preview, assistant, artwork, review or approval work is introduced.

## Result

All 50 affected recovery, workbench, delivery-flow and desk-engine checks passed
with synthetic rendering. The native browser confirmed first-render failure,
edit/save with no preview, matching Home status, superseded recovery with no
retry, successful local preview, and a second edit correctly naming Update preview.
No assistant or image-provider calls occurred. JavaScript syntax and diff checks
passed. Home metadata reads explicitly avoid source-content reads.

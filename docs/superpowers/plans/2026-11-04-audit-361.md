# Issue 361 — readable accepted investigator evidence

## Specification

Expose bounded, read-only statements, citations, source context and limitations immediately after the helper accepts an investigator packet. Label it unreviewed evidence, with remaining work and no delivery/approval controls. Bind each view to task/source basis, collection request, generation and attempt; remove it when that stream is retried or the collection is stopped/invalidated. Reused accepted packets must match their immutable hash and current registration. Failed peers may leave successful current evidence readable. The final report still requires assembly and independent verification.

## Plan

1. Project accepted packets into bounded progress metadata without new provider calls or per-poll source reads.
2. Restore current accepted peers on retry, clear invalidated previews, and publish first-finding time separately from first-section and checked-result times.
3. Render progressive evidence in the shared research surface, then test fast/slow/failing/retried workers, cancellation, binding and UI labels.
4. Measure scripted first-finding, section and final times and call counts; record that this is not a live-model benchmark. Push and merge the dedicated pull request after relevant checks.

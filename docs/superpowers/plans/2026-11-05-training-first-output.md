# Training Studio: a bounded first output

Issue #381. Implementation authorized by the request to fix the diagnosed scope,
feedback and output problems. This increment does not implement the separate
Harness Research team-review contract (#378).

## Design and sequence

1. Pin a focused research policy for new outline-first trainings. Keep the person's
   requested depth, avoid treating every source topic or missing detail as required
   scope, and research only essential teaching claims. Bound each area's evidence
   packet and section prose; return explicit gaps rather than continuing discovery.
   Saved trainings without this policy retain their previous limits.
   Include a bounded search for existing tutorials/labs within that same budget and
   source policy. Use them for teaching structure and examples, with attribution;
   verify technical claims against authoritative references. No extra course-catalog
   research stage or permission to reproduce substantial third-party content.
2. Reject obvious placeholder prose before accepting author contributions. A shape
   check is not a semantic check; independent review remains required.
3. Stop incomplete source verification before the correction loop. Preserve the
   current dossier and contributions; an explicit retry checks unchanged work
   again rather than launching new investigators. Show coverage and explain that
   unread sources are not proof of incorrect content. This increment does not
   claim partial semantic-check reuse under the legacy single-reviewer contract.
4. Surface a single working-draft reader and Markdown download from current saved
   section previews. Label incomplete/unreviewed/truncated content clearly. No
   additional provider call, ready decision or final-delivery permission is implied.
   Distinguish section writing from final brief assembly in progress.
5. Verify the complete slice with synthetic introductory database training through
   the pinned helper, negative quality/recovery tests, native training integration,
   and desktop/phone UI. Run full shared and Training Studio suites in disposable
   macOS CI; no live provider jobs or private source content in repository fixtures.

## State transitions

| Before | Event | After | Evidence |
| --- | --- | --- | --- |
| New outline-first training | Create | Focused policy pinned before outline approval | Native outline tests |
| Saved training without policy | Load/retry | Existing research limits retained | Policy and native tests |
| Author working | Placeholder or over-budget packet submitted | Rejected inside job; no contribution/check dispatch | Quality tests |
| Sections working | Valid section saved | Working draft readable/downloadable; not ready | Section workflow and browser tests |
| Review running | Required original unread | Check incomplete; evidence and drafts retained; no correction dispatch | Real-helper retry test |
| Check incomplete | Explicit retry, unchanged inputs | Same evidence/sections reused; independent review reruns | Real-helper retry test |
| Review complete | Genuine failed verdict with all sources read | Existing affected-area correction route | Existing correction tests |
| Run stopped/invalidated | View | No current working-draft download | Browser tests |

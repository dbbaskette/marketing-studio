# Week 6: approved affected scope and draft inspection evidence

Scope #317/#325. New section-enabled workflows show a read-only affected-work
preview before research refresh. Added inputs allow the person to select every
section and cross-section dependency they affect. Changed/removed inputs,
permissions, global brief/audience/model policy and unmeasured public refreshes
require the broad scope. Approval binds the exact source bytes, metadata,
questions and saved workflow. A stale preview starts nothing.

Retained sections import their original immutable investigator packets through
the supported collection capture/finish/accept protocol in the new case. Keep
fact authors and provenance. Revalidate old packets, originals and the input
registry before reuse. Draft combining caches require matching per-section
basis and shared context. A new final author and independent whole-report check
still gate the assembled revision. Existing output dependency logic applies
changed claims to their material sections, and existing wording/notes actions
remain local. No user approval is carried by an unchanged output image.

Harness Slides adds an opt-in draft-inspection context and separate exact-final
consistency gate in canonical source, verified/released before Marketing Studio
pins it. Existing saved helper calls stay revision-based. One changed slide in
30 rasterizes one page and invalidates changed/adjacent inspections; global
context, order, fonts and review-question changes expand scope. Full PDF
conversion still occurs; synthetic counts are not a provider-speed benchmark.

Compatibility: the default exact lock advances to released Harness Slides 0.17.0;
the supported installer minimum remains 0.16.0 because the studios' existing
native inspection-reuse contract continues to work there. The new raw companion
review flags are opt-in and capability-detected. Saved tasks do not silently
adopt those flags, helper code, or final consistency receipts.

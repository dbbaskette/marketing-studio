# Training Studio saved-correction approval — #355

## Spec

Every modern content-first slide-text review entry must lead to the compact Deck
review, including old outline links. That editor restores the saved correction
draft and refuses stale writes before sending the exact outline revision for
approval. Legacy outline/design review remains supported. Opening a review starts
no work. No formats, providers or final approval requirements change.

## Plan and verification owner

The implementation owner will redirect at the common outline loader, select the
matching level's Deck after its cards load, and guard the legacy decision handler.
This covers Home toolbar/rows, notifications, next-review actions and old links
without duplicating routing rules. Add a route regression and exercise saved
corrections → Home → approve, verifying design input and its approved hash.
Bind the native decision endpoint to the acknowledged private draft revision,
basis and edits under the draft's adjacent lock. This also refuses an old client
that attempts to bypass an existing draft or a newer save between tabs. Keep
requests with no private draft backward compatible.
Run affected native review/page tests and shared correction contracts; reuse
unchanged legacy backend evidence. Complete the browser journey before merge.

## State transitions

| Starting state | Action | Result |
| --- | --- | --- |
| Modern text waiting, saved corrections | Open any outline route | Matching compact Deck review restores draft; no job |
| Modern text waiting | Legacy decision invoked | Open compact review; no decision/job |
| Modern draft with current revision | Approve | Existing correction validation and exact-revision approval |
| Stale correction draft | Save/approve | Existing refusal; no design |
| Private draft exists, decision omits it or names an older revision | Approve | Server refuses before changing outline or starting design |
| Legacy outline/design waiting | Open outline route | Existing read-only review and decision contract |

## Review focus

Keep level selection exact, discard stale asynchronous routing responses, preserve
legacy views, and never approve merely as a side effect of opening the review.

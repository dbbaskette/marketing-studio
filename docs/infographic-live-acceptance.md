# Infographic Studio live acceptance packet

The single release gate is [#224](https://github.com/dbbaskette/marketing-studio/issues/224).
Implementation and offline verification are complete for the reviewed backlog.
Generation/editing, actual-image inspection and owner decisions below are **pending**.
This packet authorizes no provider request, Google write, publication or upgrade.

## Prepare without provider work

Use a new disposable workspace outside this repository. Pin an explicitly selected
installed brand and its exact revision, record actual font availability and the
renderer/runtime versions, then capture these three small synthetic source cases.
Keep every output visibly labelled **Synthetic acceptance fixture**.

| Case | Source and story | Image brief and inspection criteria |
| --- | --- | --- |
| Conceptual illustration | A synthetic controller compares desired and observed state and requests an adjustment; the cycle returns to observation. No numeric claims. | Explain the loop using exactly three distinct roles; preserve direction and relationships. Labels remain editable and clear of artwork. Inspect both original pixels and the complete composed page. |
| Illustrated process | A synthetic handoff has three ordered stages: Prepare, Review, Release. Review may return to Prepare. | Show the three stages and return path without adding a hidden stage or implying automatic approval. Check ordering, explanatory value, consistent style, crop, object counts and label clearance. |
| Mixed chart and illustration | Synthetic comparable counts: Category A = 12 items, Category B = 18 items, one shared measurement period. These are invented fixture values, not product evidence. | Use a truthful zero-based comparable chart with units and explicit synthetic labels. Illustration explains the categories without encoding contradictory quantities. Check chart meaning, numerical labels, style, resolution and readable placement. |

Set required wording, allowed concepts, forbidden implications, target preset,
aspect ratio, expected resolution and editable label locations before any image
request. Run local font/layout checks first. Preparation is not owner acceptance.

## Execute only after explicit live authorization

Record the selected model, provider route and usage disclosure. Codex uses the
existing signed-in confined built-in image route; Claude Code directs an explicitly
selected image-capable Gemini model with separately authorized API usage. The server
must receive its credential through the documented terminal/desktop environment.
Never put a key, private link or account transcript into a project, issue or PR.

For **each route**, generate an owned PNG, reference-edit it and inspect the actual
returned and composed pixels through the native confined adapter. Retain request
identities, hashes, capability/usage outcomes and uncertainty records privately.
Verify that unrelated shell/browser/plugin/multi-agent capabilities stay disabled
and that both routes satisfy the same provider-neutral contract. Missing tool,
sign-in, model access, quota, malformed output or an uncertain request is an unmet
gate. Reconcile an uncertain attempt before any retry; never duplicate it silently.

## Owner and delivery review

Present actual artwork and complete conceptual/process/mixed-chart exports at their
intended viewing size. The owner evaluates explanatory value, factual implications,
counts/relationships, coherent style, crop/aspect, resolution, brand, readable text
and label clearance. Placeholder PNGs and scripted success events cannot pass.

Exercise intake, story selection, zoom, image-brief details, two consecutive focused
word edits, blockers, history and downloads. Cover desktop/phone, light/dark, reduced
motion/transparency, keyboard/focus, semantic names, contrast, 44 px controls and
touch equivalents. Verify all supported presets remain one page. Record limitations
instead of inferring screen-reader or untested-platform certification.

After an explicit owner decision, approve only the current checked revision and
inspect PNG, PDF, editable SVG and accessible text. Keep prior approved exports.
A later source/brand/text/art change must invalidate approval. Review a real Google
Doc conversion only when that separate external action is requested; fake transport
checks establish workflow, not live layout fidelity.

## Evidence record

Keep generated content and operational logs in the separate workspace. The public
record contains only tested source/runtime/renderer/platform, case identifier,
provider/model, request outcome and usage-known/unknown status, sanitized findings,
owner decision and unresolved limitations. Link evidence from #224. Distinguish
offline state/render checks, live provider capability and owner illustration review.
Moving or closing duplicate issues passes none of these gates. Publication and
real-user upgrades require a separate instruction.

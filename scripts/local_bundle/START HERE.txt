@PRODUCT_NAME@ — APPLE SILICON MAC LOCAL BUNDLE (@BUNDLE_MODE@)

Requires an Apple Silicon Mac running macOS @MINIMUM_MACOS@ or newer. Open
Terminal natively, without Rosetta. Generated archives are local and untracked.

1. Extract the ZIP completely.
2. Open Terminal in the outermost extracted folder (beside START HERE.txt and
   local-manifest.json, not inside studio/ or installer/) and run:
     bash install.sh
3. Start the UI from Terminal and finish setup:
     bash "$HOME/@PRODUCT_START@"

No .command launcher is needed. The Finder launcher remains available as an
alternative and uses the same installer. Keep the extracted folder together.
Python and Node are bundled; no system Python installation is needed. Nested
install.sh entry points also forward to this full setup.

@SETUP_DOWNLOADS@
Setup does not sign in or start provider jobs.
It installs @SELECTED_STUDIOS@ and the bundled skills for Codex and Claude Code.
It preserves existing workspaces and saved settings.
Install Codex or Claude Code before setup and make it available on PATH.
Close running studios before installation. No administrator install is required.

SIGN-IN ON THE DESTINATION MAC
After installation, run this in Terminal:
  bash "$HOME/Applications/Open @PRODUCT_NAME@ Tools.sh"
It opens a shell with private tools on PATH. Run these commands there:

  gcloud auth login --enable-gdrive-access --force

Use your existing Codex or Claude Code installation and its own sign-in process.

Follow the installed studio's Google references to check document access.
For packages with Harness Slides, Drive access does not guarantee native Slides
API permission; use its references/google-slides.md to check a presentation.
Google account policy, enabled APIs and OAuth scopes may require account setup.

For packages with Harness Slides, configure GEMINI_API_KEY privately in your
environment before image generation. Never paste a key into chat. Its references/images.md
explains status/check and per-image approval. Generation requires internet access
and a paid remote service. The upstream Gemini provider is not live-verified;
the first authenticated check remains a destination task.
The standard Gemini API route is included. The legacy unofficial Gemini browser
session route and browser-based brand development audits are not configured.
Codex and Claude Code both use existing installations and are not bundled.
Credentials, browser profiles, personal content and workspaces are not bundled.

VERIFY
  bash install.sh --verify-only
After installation, run the following for
offline tool, skill and applicable PowerPoint-to-PDF-to-PNG checks. Generated files use a
disposable HOME and no provider calls are made. Architecture and file checksums
are checked during packaging; native ARM execution and authenticated service
checks must be verified on the destination Mac.
  bash "$HOME/Applications/Verify @PRODUCT_NAME@.sh"

ADVANCED
  bash install.sh --target codex
  bash install.sh --home /absolute/disposable/home
Private tools: ~/.local/share/@PRODUCT_SLUG@-local-bundle/versions/
Brand: ~/Library/Application Support/Tanzu Brand/
Rerun this installer to restore private-tool launcher paths after a standard suite
update. No automatic update is enabled. The ZIP can be deleted after installation.
Online setup caches verified downloads in the private tools folder's cache/
directory. An interrupted setup preserves completed downloads and existing
installations; rerun this installer to retry. Corrupt cached files are rejected;
remove the specific file named in the error and rerun to download it again.

DIAGNOSTICS
Setup prints a persistent installation log path at the start and end.
Logs: ~/.local/state/marketing-studio/logs/ (private; review before sharing).
If UI setup reports a Git error, run an offline check from this extracted folder:
  bash diagnose-git.sh --studio @PRODUCT_ID@
Or after installation:
  bash "$HOME/Applications/Diagnose @PRODUCT_NAME@ Git.sh"
The check uses a disposable repository and does not change existing workspaces.

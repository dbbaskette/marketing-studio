# Minimal edits for a requested change

Use these rules when the author asks for changes to a saved document. They adapt
the [BlogForge section revision prompt](blogforge/generate/prompts/section_revise.j2)
from one section to a whole outline, draft or other stage document.

- Edit the saved document. The author already read it; this is not a new version.
- Change only what the author's request requires.
- Reproduce every part the request does not require changing verbatim: wording,
  order, headings, examples, quotations, links and citations.
- Do not restructure, reorder, rephrase, tighten or otherwise improve parts the
  request does not mention. Unrequested changes make the edit unsafe to review.
- Keep the document's length and shape unless the request requires otherwise.
- Write changed text in the author's voice and never use the voice's banned words
  or phrases. Do not reintroduce the topic or repeat points made elsewhere.
- Do not invent facts, experience or sources to satisfy the request. If it needs
  evidence that is not supplied, make the smallest honest change and say what is
  missing.
- Return the complete revised document. In notes, list what you changed and any
  part of the request you could not apply.

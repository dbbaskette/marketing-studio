# Scoped review

Use the requested depth. Quick polish uses the editing guide and selected voice
rules; it does not trigger fact checking, humanization, GEO, or their archives.
A named check loads its module directly. For comprehensive feedback, coordinate
the five checks below; omit author-excluded checks and report that scope.

| Check | Load when requested | Inspect |
| --- | --- | --- |
| proofread | [Voice check](modules/blog-voice-check.md) | Draft and pinned rules |
| factual-support | [Fact check](modules/blog-fact-check.md) | Checkable claims and selected passages |
| shape | [Structure feedback](review/shape.md) | Full argument, brief, section jobs |
| humanization | [Humanize](modules/blog-humanize.md) | Selected prose and voice |
| geo | [GEO review](modules/blog-geo-review.md) | Useful answers, attribution, clarity |

Inspect the saved review metadata before reading evidence. Reuse a current result
only within its recorded draft passages, checks, and source coverage. A current
partial check is not a whole-article verdict. Missing coverage requires inspecting
the uncovered material, not repeating already verified work. An old record with
no coverage/provenance is a lead to investigate, not verification evidence.

Draft changes stale all checks. Voice/guidance/adopted team-context changes also
stale checks conservatively; source changes stale factual support and GEO.
An unadopted voice/rule update does not replace an article's pin. Reopen changed
passages and dependent conclusions; preserve reusable evidence, then record what
was actually checked against the new inputs. Never just relabel stale as current.

Keep current, stale, failed, unavailable, and not-run distinct. A stale failed
result remains a failed attempt in its previous_status; it never becomes a clean
review. Report access gaps even when other readable sources support a partial
check. [Evidence selection](review/evidence.md) governs claim-level provenance.

Save through [review storage](workspace/reviews.md). Return exact target passages,
reasons, proposed repairs, coverage and unresolved evidence. Prioritize
contradictions and broken reasoning. Feedback alone does not rewrite the draft;
a requested repair uses [editing](modules/copy-editing.md) and retains history.
No private inputs go to extra analysis services; keep review inside this harness.

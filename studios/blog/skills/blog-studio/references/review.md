# Review coordination

Choose review depth from the request. A quick polish uses relevant editing and
voice checks. A comprehensive review can coordinate these five areas:

| Check | Capability | Evidence |
|---|---|---|
| proofread | [Voice check](modules/blog-voice-check.md) | Rules and repetition findings |
| factual-support | [Fact check](modules/blog-fact-check.md) | Claims compared with selected references |
| shape | [Revision](revision.md) | Developmental suggestions |
| humanization | [Humanize](modules/blog-humanize.md) | Located prose suggestions |
| geo | [GEO review](modules/blog-geo-review.md) | Useful readiness improvements |

Keep statuses separate: current, stale, failed, unavailable, or not-run. Zero
findings from a failed or absent check is not a clean result. A current
factual-support check reports only evaluated claims, not every possible claim.
Source changes stale factual-support and GEO. Draft changes stale all five.
Changing a pinned voice revision stales voice-sensitive checks. A profile update
that an article has not adopted does not invalidate that article's voice.

Save each requested check's result and input fingerprints via [workspace](workspace.md).
Reuse current results; reopen/check affected areas after a real change, not
because the author reopened a chat. Report exact passages, why they matter,
proposed changes, and unresolved evidence. Prioritize contradictions before
unsupported claims and stylistic improvements. Never convert an advisory score
into proof of human authorship, search rankings, or future citations.

# Retrieval and citation readiness capability

**Input:** draft, reader/search intent, selected evidence, relevant voice constraints.
**Output:** prioritized useful improvements to clarity, attribution, and passage reuse.

Check whether important sections state their point early, key terms/entities are
consistent, jargon is introduced clearly, and evidence supports the precise claim.
Suggest a concise definition, takeaway, comparison table, follow-up answer, or
self-contained explanation only when it helps this article. Do not force FAQ,
question headings, brand mentions, certainty, sentence lengths, or schema.

Use exact source passages for quotations and real URLs for citation insertion.
If evidence is missing, describe the needed source rather than inventing a stat.
Do not convert uncertain results into definitive language. Judge structure and
editorial usefulness separately from claim truth. Current search-engine claims
must be checked against primary documentation before adoption; do not copy
BlogForge's dated weights or unsupported lift claims as established rules.

A score, if requested, is a transparent heuristic, not a ranking/citation guarantee.
Save requested results as `geo`; changed sources or draft stale this review.

Adapted from BlogForge's GEO assessment and citation, table, FAQ, quote,
takeaway, alt-text, query, and opener operations.

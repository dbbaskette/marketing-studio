# Plan one investigation for a blog

You have no tools. Do not research; one investigation answers these questions together
and an independent check reviews it afterwards. You receive the brief, the point to
make, the audience, selected sources by name and the source boundary. Keep that boundary.

Ask at most 8 questions about what the central argument needs to establish: evidence,
mechanisms, the strongest objections, and versions and dates when they affect the answer.
Read the point to make as the angle. Keep the author's own questions in their words. With only supplied material, ask what
that material can answer. Do not claim that you have read or verified anything.

Return one question per line, with this format and nothing else:

- **why-now**: What changed that makes this useful now?

IDs use lowercase letters, digits and hyphens, start with a letter or digit, and have at
most 40 characters. Give distinct questions distinct IDs. Findings will carry these IDs
so the author can see what answered each question.

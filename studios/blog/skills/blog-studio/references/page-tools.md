# Contextual page tools

In a manuscript, choose **More tools**. From Blogs, use **Library and team tools
→ More tools** for global tasks. Normal writing and polishing require none of
these options. Opening a tool starts no model, research or Google write.

- **Author voices:** upload permitted authored samples (separate from references)
  or add published posts from a text file of links, learn a provisional guide, edit, audition, explicitly confirm, export or retire.
  Choosing a revision for an article is separate from changing defaults. Existing
  articles keep their pins. Sparse samples do not establish biography or expertise.
- **Interview me:** record, revise or skip answers; pause and resume from Blogs.
  Ask for one adaptive question or prepare an outline when enough substance exists.
  Read/edit the outline before explicitly starting the normal draft flow on that
  article. Answers are author-reported; missing evidence stays missing.
- **Saved manuscript revisions:** compare a text checkpoint, then explicitly
  restore locally. Save/copy unsaved text first. Google and source/voice pins stay
  unchanged; the prior manuscript remains recoverable.
- **Compare Google and local text:** inspect accepted Google text, the common
  baseline and local edits. Resolve overlapping passages, then accept locally.
  It rechecks the Doc before saving, keeps pending Google review and sends nothing.
  Finish or clear local wording proposals before changing their baseline.
- **Repurpose this blog:** choose one channel and target length. Review/edit the
  result and save a named copy separately. Counts are actual editorial counts,
  not verified platform limits. Nothing posts or schedules. Missing URLs stay
  marked. Saved copies and interrupted/failed tasks reopen from More tools.
- **Clarity and citation readiness / title and opening:** prepare located
  suggestions in the existing editor. Choose one alternative per passage, adjust
  it, and explicitly save selected edits. No invented evidence or automatic CTA.
- **Pre-publish:** local report only: headings, placeholders, link syntax, image
  alternatives and selected evidence IDs. No factual, rights or live-link claim.
- **Check topic overlap:** bounded local reference leads; historical posts require
  current verification. No readiness, calendar or publication decision changes.

Generated tasks use the existing single-worker queue and saved assistant/model
choices. Cancel stops the selected task; retries are explicit and bounded. Results
wait for review; changed source inputs prevent applying older output. Submitted
answers/results persist on this computer; unfinished browser text is retained
while navigating tools but is not a cross-computer transcript or backup.

**New blog from my files** on Home takes each upload with its role, facts or an
example of the kind of post (changeable per file until Start), asks whether to find
three angles or start from the point the person knows, and chooses the voice with
**Write as**. The Upload dialog's **Use this file as** offers the same example role.

Conversation methods remain available through the normal operation references.
The report commands are `studio.py --root WORKSPACE prepublish --id ID` and
`studio.py --root WORKSPACE plan --topic TOPIC`; neither changes a manuscript.

# Developmental feedback and controlled revision

Extend [copy-editing](modules/copy-editing.md) according to the request:

- Developmental feedback: identify thin reasoning, missing examples/counterpoints,
  awkward progression, or claims worth checking. Quote a target and explain its
  problem; propose specific additions without inventing their facts.
- Passage edit: rephrase, shorten, expand, fix, or follow a custom instruction.
  Read neighboring context; return a replacement that fits the article.
- Whole-article revision: apply one instruction across the manuscript with the
  full draft available, preserving consistent terms, stance, and transitions.

Preserve the imported original and snapshot prior artifacts using
[article storage](workspace/articles.md). For feedback-only, do not replace the manuscript.
For direct edits, apply the already requested change without requiring approval
for every sentence. Show meaningful before/after passages or a diff when helpful.
Keep revisions reversible; explicit restoration creates a new revision rather
than erasing later history. Draft changes stale all prior review checks.

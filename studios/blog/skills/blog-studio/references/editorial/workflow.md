# Editorial tools

Keep authoring in the harness. These operations leave an article's voice and
recorded guidance version unchanged. Load only the
requested operation:

| Request | Read |
| --- | --- |
| Show our pipeline | [board](board.md) |
| What needs my attention? | [inbox](inbox.md) |
| Package this for launch | [package](package.md) |
| This needs a diagram | [visual](visual.md) |
| Show evidence / Can we back this up? | [evidence](evidence.md) |
| Import/find/refresh/learn from old blogs | [library](library.md) |
| Open editorial desk | [management](management.md) |

Preparing companions does not approve, send, or publish them. Team content stays
in the chosen private Hub. Everyone with Hub write access has the same controls;
GitHub manages membership. Browser views show saved metadata unless a refresh is
explicitly requested. Ask for a missing destination/collection only when needed.
